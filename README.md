# 🚀 Cosmic Strike – 2D Space Shooter

A space-themed arcade shooting game developed using **Python and Pygame**.

Take control of a spaceship, fight enemy spacecraft, dodge incoming laser attacks, and survive increasingly challenging waves of enemies.

## 🎮 Features

- 🌌 Procedurally generated space background
- 🌙 Detailed moon, mountains, nebula and animated stars
- 🚀 Custom-designed player spaceship
- 👾 Multiple enemy spaceship designs
- 🔫 Player and enemy laser systems
- 💥 Particle-based explosion effects
- ❤️ Player health and health bar system
- 🏆 Score tracking and progressive levels
- ⚡ Increasing difficulty as the game progresses
- 🔄 Restart functionality after game over

## 🛠️ Technologies Used

- Python
- Pygame
- Random
- Math

## 🎯 Controls

| Key | Action |
|---|---|
| ← / A | Move Left |
| → / D | Move Right |
| ↑ / W | Move Up |
| ↓ / S | Move Down |
| SPACE | Shoot |
| R | Restart after Game Over |
| ESC | Exit Game |

## ⚙️ Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Cosmic-Strike.git
   ```

2. Navigate into the project directory:

   ```bash
   cd Cosmic-Strike
   ```

3. Install Pygame:

   ```bash
   pip install pygame
   ```

4. Run the game:

   ```bash
   python3 spaceship_battle.py
   ```
